# WorkIT 

An IT job advertising platform inspired by pracuj.pl. This project was built as a hands-on learning experience to practice developing a RESTful API, building a Single Page Application (SPA) with React, handling dynamic routing, and implementing secure JWT-based authentication.

## General Information
WorkIT separates the client and server into two distinct architectures. The system consists of an independent Laravel-based REST API and a React frontend, interacting seamlessly via asynchronous HTTP requests. The primary focus of this project is to understand the flow of data between a separated frontend and backend, secure endpoints, and manage application state based on user authentication.

## Technologies
**Frontend:**
* React (Single Page Application)
* React Router (Dynamic routing and views)
* JavaScript
* SCSS / HTML5

**Backend:**
* PHP / Laravel (REST API)
* MySQL (Database)
* JSON Web Tokens (JWT) for Authentication
